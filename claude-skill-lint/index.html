Install

Python 3.8+, no dependencies. Exit non-zero on ERROR so it drops into CI.

Install script

curl -fsSL https://raw.githubusercontent.com/gesh75/claude-skill-lint/main/install.sh -o install.sh
bash install.sh
skill-lint ~/.claude/skills

GitHub Action

uses: gesh75/claude-skill-lint@v0.5.0
with:
  path: skills
  profile: claude-code
  min-score: "80"
